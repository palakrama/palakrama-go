# Changes v0.1.0

- First version: package `middleware` with `Operational`, moved unchanged from the nine services (their `internal/delivery/http/middleware/operational.go` were byte-identical), with tests for identity headers, request ids, maintenance mode, and panic recovery.
- `RequireKey`, `MatchKey`, `KeyOf`, and the rejections `RejectText`, `RejectTextUnconfigured`, `RejectJSON`: the service-key check of eight services (auth, comment, communication, media, order, rsvp, site, stats), which each had their own copy. Several keys per route, with the key used recorded for the handler (media's client and admin keys). Tests for matching, recording, and each rejection.
- Package `httpx`: `WriteJSON` and `DecodeJSON` (one JSON value, unknown fields refused), which all nine services had their own copies of. Tests.
- Package `client`: the JSON client for calls between services (`New`, `Post`, `Get`, `Do`, `StatusError`), replacing the hand-written requests in auth, blog, comment, order, and site (and comment's `jsonhttp` and site's own JSON client). Tests for headers, bodies, error answers, timeouts, and bad answers.
- CI: vet and test.
